# KDD Process for Heart Disease Prediction

This project applies the **KDD (Knowledge Discovery in Databases)** process to the **Heart Disease UCI Dataset**. The goal is to predict the presence of heart disease in a patient using machine learning techniques.

## Project Overview

The **KDD process** involves the following steps:
1. **Selection**
2. **Preprocessing**
3. **Transformation**
4. **Data Mining**
5. **Interpretation/Evaluation**

In this project, we explore how the KDD process can be applied to predict heart disease and evaluate the performance of various machine learning models.

### Dataset

The dataset used in this project is the **Heart Disease UCI Dataset** from the UCI Machine Learning Repository. It includes 13 features such as age, sex, chest pain type, resting blood pressure, cholesterol levels, and more, with the target variable indicating the presence of heart disease.

You can find the dataset on [Kaggle](https://www.kaggle.com/code/mragpavank/heart-disease-uci).

### Key Methodologies and Tools
- **Python** for data manipulation and analysis.
- **Pandas** and **NumPy** for data processing.
- **Scikit-learn** for machine learning models.
- **Matplotlib** and **Seaborn** for visualizations.
- **PyCaret** for low-code machine learning tasks.
