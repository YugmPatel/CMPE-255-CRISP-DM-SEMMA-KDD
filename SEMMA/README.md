# SEMMA Process for Titanic Dataset: Survival Prediction

This project applies the **SEMMA (Sample, Explore, Modify, Model, and Assess)** methodology to the **Titanic Dataset** to predict the survival of passengers using machine learning models.

## Project Overview

The **SEMMA process** involves the following steps:
1. **Sample**: Select a representative sample from the dataset.
2. **Explore**: Examine the data for patterns and relationships.
3. **Modify**: Clean and prepare the data for modeling.
4. **Model**: Build models based on the prepared data.
5. **Assess**: Evaluate the model's performance using appropriate metrics.

This project demonstrates how the SEMMA process is applied to the Titanic dataset, which includes features such as age, gender, class, and more, to predict survival.

### Dataset

The dataset used is the well-known **Titanic Dataset** from the Kaggle competition "Titanic: Machine Learning from Disaster." It contains passenger information like name, age, sex, ticket class, and whether they survived.

You can find the dataset on [Kaggle](https://www.kaggle.com/code/alexisbcook/titanic-tutorial/input).
